!!! note "This guide is still under development"

Thank you for contributing to MontiCore or one of the projects
within its ecosystem.

We welcome all kinds of contributions, including, but not limited to,
bug reports, feature suggestions, bug fixes or new features.

## Code Change Requests

1. Please check if we have an open issue or
   discuss your proposed solution with the maintainers before creating a PR.
2. Fork this repository and create a new branch from the `dev` branch:
    * Please make sure you have an up-to-date `dev` branch
    * Please use meaningful names for your branches
      e.g., `git checkout -b feature/my-feature-name`
3. Please make sure that your complete workspace only uses UNIX line
   endings (LF) and all files are UTF-8 without BOM.
4. Modify the files
    * See [BuildMontiCore.md](BuildMontiCore.md) for how to build and test locally.
5. Please include tests with your changes.
6. Push to the branch of your fork, e.g. `git push fork feature/my-feature-name`
7. Open a Pull Request against our `dev` branch.

We aim to review PRs in a timely manner, but please be patient.
Our CI runs tests both within the project 
and runs tests against the MontiCore ecosystem ("MontiVerse").

Thank you for your contribution.
